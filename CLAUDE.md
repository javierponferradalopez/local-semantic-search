## Agent skills

### Issue tracker

Issues live as GitHub issues in `javierponferradalopez/local-semantic-search`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context — one `CONTEXT.md` and one `docs/adr/` at the repo root. See `docs/agents/domain.md`, also to decide the kind of the ADR of a new rule: a decision or a convention.

### Conventions

Before you add or change a class or a test in `<package>/`, read the accepted `docs/adr/*-convention-<package>-<topic>.md` of each kind of class you touch.
